# Java-Project-WebPage
# 쇼핑몰 웹페이지 제작 프로젝트


## 🖥️ 프로젝트 소개
로그인, 게시판, 장바구니 기능을 구현한 쇼핑몰 웹페이지입니다.
<br>

## 🕰️ 개발 기간
24.12.19 - 25.01.09


## ⚙️ 개발 환경
* JDK 17.0.13
* Eclipse : 2024-06 (4.32.0)
* Oracle SQL Developer : 24.3.0.284


## 📌 주요 기능
#### 1. 세션을 통한 로그인, 로그아웃 기능
#### 2. 회원가입, 회원정보 수정, 탈퇴 기능
#### 3. 답변형 게시판 기능
#### 4. 회원별 장바구니 기능
#### 5. 상품 검색 기능
